# 红果免费漫剧 · 集间广告自动上滑(GKD 规则)

给 [GKD](https://gkd.li) 用的个人订阅规则:看「红果免费漫剧」时,每集之间插入的倒计时广告结束后,自动上滑进入下一集——连续追剧全程不碰手机。

**仅适配独立 App「红果免费漫剧」(包名 `com.kylin.read`)**,主 App「红果免费短剧」(`com.phoenix.read`)不在适配范围。

## 规则内容

| 组 | 功能 | 说明 |
| --- | --- | --- |
| 集间广告-上滑继续 | 核心功能 | 检测到「上滑继续」提示后约 1 秒自动上滑(0.7→0.3 屏高、200ms);提示仍在则约 2 秒间隔重试,消失即停 |
| 开屏广告-点击跳过 | 辅助 | 进 App 后 10 秒内自动点「跳过」或穿山甲开屏跳过按钮 |
| 广告-点击跳过/关闭广告 | 辅助 | 部分广告素材自带按钮:[跳过]直接点,[关闭广告]延迟 1.5 秒后点 |

## 安装

前置:手机已安装 GKD 并开启无障碍权限。

### 方式一:本地粘贴(推荐)

1. 复制 [`gkd.json5`](gkd.json5) 的**全部内容**;
2. GKD → 首页 → **订阅** → **本地订阅** → **应用规则** → 粘贴并保存;
3. 打开各规则组的开关。

> ⚠️ 是「**应用规则**」入口,不是「全局规则」。本地订阅里应用规则 / 全局规则是分开的编辑入口,格式互不通用;完整订阅对象格式只用于远程订阅。

### 方式二:远程订阅(自动更新)

GKD → 订阅 → 添加订阅,粘贴以下任一链接:

- jsDelivr CDN(国内网络通常更稳):
  `https://cdn.jsdelivr.net/gh/iz123456/hongguo-manhua-ad-skip@main/gkd.json5`
- GitHub Raw(部分网络不可达):
  `https://raw.githubusercontent.com/iz123456/hongguo-manhua-ad-skip/main/gkd.json5`

## 已知限制

- **倒计时本身跳不掉**:App 规定倒计时内上滑无效,自动化只能做到「倒计时结束瞬间立刻滑」,约 7 秒等待是下限。
- 广告素材由穿山甲 SDK 投放、随广告主变化,App 改版可能导致规则失配;失配时可在 GKD 抓广告页快照,对照修改选择器。
- 仅在作者设备(OPPO,ColorOS)上实测通过,不承诺所有机型与版本。
